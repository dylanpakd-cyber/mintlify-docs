Warmr has three plans: Solo, Rack, and Scale. Every plan includes ramp before each post, auto-posting on a schedule, TikTok, Instagram, X, and LinkedIn, and MCP. Phone count, Cloud Drop, and the API key are what change.

## Plan comparison

| | Solo | Rack | Scale |
|---|---|---|---|
| **Price** | $50/mo | $150/mo | $999/mo |
| **Trial** | 7 days | 7 days | None |
| **iPhones** | 1 | Unlimited | Unlimited |
| **Accounts** | Up to 8 per platform | Unlimited | Unlimited |
| **Usage** | Unlimited | Unlimited | Unlimited |
| **Cloud Drop** | 5 GB | Unlimited | Unlimited |
| **MCP** | Included | Included | Included |
| **API key** | No API key | Included, for whitelisting | Included, for whitelisting |
| **Scale community and coaching** | — | — | Included |

Each iPhone holds up to 8 accounts per platform. Solo is that one iPhone. Rack and Scale add iPhones, so the account total is unlimited.

Solo and Rack include a 7-day trial. A card is required. Cancel before day 7. Scale is $999/mo, limited to 3 spots, and has no trial.
